# L4 分层标注与几何辅助

## 选择标注范围

先选择房间，再选择功能分区，查看本区参考，最后选择橙色家具组团。顶部导航在滚动时保留；也可以在画布选择房间、分区与组团，或在右侧列表直接定位已有实例。列表和连续复核会按实例保存的父级 ID 同步导航，不重新推断归属。

其他分区的实例弱化显示，不能在画布中直接编辑。切换房间或分区会清除下级 Focus 和批量勾选；绘制中请先完成或按 Esc 取消。全任务复核进度仍统计全部实例。

L4 上级参考不再常驻显示文字。右侧“本区上级参考”区分 L1 开口、L2 交通/视觉连接、L3 墙障碍，支持分类开关、“本房间背景”和“全图概览”。没有分区归属证据的参考不作为本区确定关联。来源异常仍通过原来的上游入口和手动应用流程处理。

同一可通行逻辑区域仅显示并集外轮廓和真实孔洞边界，内部三角接缝隐藏。原始结果、分块和 ID 完整保留；并集失败时保留原分块并提示原因。以上 Focus、开关及显示变化不会使复核失效。

## 空间进度与待办导航

进入 L4 后，右侧“空间进度”按房间 → 功能分区 → 家具组团 → 实例展示。无需先选择房间即可查看数量；零实例组团也会列出。顶部下拉框和画布空间名称显示简短进度。

- “已有实例 X/Y 组”表示有实例的组团数量，不是家具数量或标齐比例。“待检查空组团”提示检查尚无实例的父组团，不自动判定漏标；“无家具组团”不算完成。
- “已复核／待复核／需处理”沿用现有实例校验与有效复核指纹，多分块只计一次。“已有实例均已复核”不代表已经排除漏标；仍有空组团时两种信息同时保留。
- 展开箭头仅展开列表；点击空间名称切换 Focus。空间筛选和“仅看待办”只过滤列表，不改变全任务计数、标注或画布范围；当前选中路径不匹配筛选时仍会标明显示。
- “定位待办”仅查找对应空间内的目标。“下一个待办”优先当前分区，再当前房间和其他房间，同范围优先问题、空组团、待复核实例。它只定位，不自动创建或复核；浏览一轮不等于处理完成。
- “确认并下一个”保持原连续复核流程，只推进待复核实例。主动从空间概览切换目标会暂停连续复核。
- 来源或归属异常单独列出，不按名称或几何猜测父级。来源过期时统计基于已加载参考，应先通过既有上游入口处理。
- 绘制、方向草稿或几何预览未结束时，先完成／取消再切换。操作后保存失败时各层进度统一保留在保存前；仅重试保存不会重复创建或确认。普通编辑显示的是当前窗口进度，草稿保存不等于正式提交。

实现阅读顺序：`furnitureInstances/scope.js` 提供空间身份，`spatialProgress.js` 将既有复核快照汇总到各层，`reviewSession.js` 负责共享显示快照和导航，`FurnitureSpatialTree.jsx` 呈现右侧概览。上述状态仅存在于当前标注会话；不新增标注字段、API、数据库迁移或家具类别。

## 使用组团轮廓新增实例

1. Focus 目标组团，在“轮廓创建类别”中人工选择类别。
2. 点击“使用本组轮廓创建实例”。系统新增一个实例，保留父组团及已有实例，自动选择新实例并回到 Move。
3. 检查类型与轮廓，按需标注方向，然后人工复核。

支持旋转矩形、多分块、凹多边形和孔洞。已有实例不阻止新增；同组、同类、同完整轮廓的快捷创建会被阻止，并提供定位入口。不同类别允许重叠，普通手绘规则保持不变。新实例朝向为 unknown，几何旋转不代表正面方向。

创建会先保存草稿、检查上游版本，再原子写入并保存。后置保存失败时使用“重试保存”，不要重复创建。一次撤销/重做对应整个实例。

## 旋转、缩放与恢复预览

选中一个矩形实例或矩形分块后，可输入角度、按 0.1°/1° 微调，或选择父组团的具体边以平行对齐。“三点矩形”以前两点定方向，第三点定宽度；绘制时显示原图像素尺寸与角度。

角度编辑首先形成独立预览。可输入或拖动预览中心，改变尺寸比例；“按目标角度适配”固定中心，以最多 40 次二分搜索求不大于原尺寸的等比合法轮廓，宽高至少各 1 原图像素。它不寻找任意凹面中的全局最大矩形。

只有合法预览才能应用；无解时调整中心、缩小或改用多边形。Esc/取消保持原标注。应用后保留身份、父级和方向证据，并使复核失效；不合法的原方向证据需人工重标。旧有轻微越界的矩形也可通过预览尝试向内移动或缩小。

旋转和固定边缩放统一在原图像素坐标计算，随后转换为百分比存储。关闭吸附仍保留父级边界、孔洞和同实例分块不重叠约束。

## 数据与部署兼容

本功能沿用 28 类和现有 L4 结果契约，没有新增 API 路径、数据库迁移或 Schema 版本。原 lineage 版本可读取新增实例；回退仅切换镜像和部署配置，不以旧数据库覆盖后续标注。

验证用例包括 `hierarchyGeometry`、`hierarchicalWorkflow`、`connectivityParity`、Image 家具模型和复核会话测试。连接显示与既有 GraphML 导出共同使用 `examples/l4-hierarchy/connectivity-cases.json`。
