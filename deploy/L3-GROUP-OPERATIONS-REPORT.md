# L3 家具组团求并集与复制

日期：2026-10-06。功能提交：`10312fbf698a41deb30f5848d9d3c6b1b236b438`。

## 使用方式与范围

- 同一父功能分区内，在“预览组团”勾选多个家具组团，选择合并类型后点击“求并集合并”。同类默认沿用类型；不同类要求选择合并后的类型。预览编号与组团卡片对应，勾选项轮廓加粗。
- 并集消除相接／重叠部分的内部边界；不填充实际空隙或孔洞。多个不相接部分仍归为一个逻辑组团，支持整体拖动；整体移动保持组成块之间的相对位置。
- 在画布或 Regions 选中组团，点击顶部“复制选中组团”；也可点击预览卡片的“复制组团”。保留类别、说明、轮廓与矩形旋转，复制所有组成块，分配独立组团 ID、逻辑 ID 和结果 ID。不会复制原对象的手工 Relations；窗口投影由正常保存流程针对新对象生成。
- 默认向右下偏移 4 个原图像素；若越出父分区，尝试其他方向、2 或 1 像素偏移；没有空间则原位复制。绝不通过裁剪或缩小副本来容纳偏移。副本自动选中并切至移动工具。
- 复制后可暂时与原组团重叠，便于用户拖到目标位置；现有重叠校验仍会在生成可通行区域或正式提交时提示。已有可通行区域随输入变化标记过期，需重新生成与复核。
- 合并、复制使用现有保存／参考版本检查／恢复备份／单步撤销流程；只读、绘制中与失效参考不执行。合并涉及手工 Relations 时继续阻断，避免静默丢失关系。
