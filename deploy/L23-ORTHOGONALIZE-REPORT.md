# L2 / L3 Polygon 正交化验收

## 使用与约束

- L2：选中功能分区 Polygon，右侧区域属性显示“正交化（横平竖直）”。不要求预先选择绘图类别。
- L3：选中家具组团的可编辑 Polygon 组成块，顶部已有的组成块编辑工具旁显示同名按钮。多组成块仅处理明确选中的一个完整、无孔组件；不允许单独处理用于存储的三角拆分片段、只读参考或自动生成区域。
- 沿用 L1 算法：按原始图片宽高拟合水平／垂直边，共享坐标统一取整到原图像素。保持区域及顶点 ID、标签、父级归属、组团身份和来源信息；几何变化按原有规则更新上下文与复核状态。
- 父级约束使用保存的归属，不使用当前 Focus 替代。吸附结果越界、塌缩、反向或自交时保留原形状并提示。该操作关闭二次边界吸引，避免把正交结果重新拉歪，仍执行父级包含校验。其他拖动及绘图行为保持原有吸附设置。
- 成功操作为一次可撤销编辑；异常时连同关联复核信息一起恢复。已经正交且对齐像素时不产生新撤销记录。只读、比较、保存、绘制未完成等状态禁用操作。
- 没有修改后端 API、数据库或项目模板。本轮仅扩展正交化按钮，未实施之前讨论的 L2 选中即编辑交互改造。
