# L4 共用家具实例类别

日期：2026-10-06。功能提交 `dca2b61d`，刷新选择修复 `bc47f35a`。

## 使用

打开 L4「新建」类别菜单，在搜索框输入新名称。名称与已有类别或别称不同，便会出现「创建“名称”类别」。点击后选择现有九个大类之一，再点「创建并刷新类别」。系统先保存草稿，成功后刷新页面。已有实例不会被自动改成新类别；修改已有实例仍使用右侧「当前实例类别」。

类别由当前工作区管理员创建，当前工作区所有现有 L4 项目共用；以后通过项目 Create 层级流程创建的 L4 项目自动继承。其他已打开的项目需刷新后看到新增类别。类别名称标准化、长度限制为 40 个字符；重复名称不会产生重复类别。不包含类别删除、改名或新增大类功能。

## 数据与兼容

组织数据库新增 `furniture_catalog` JSON 字段（organizations 0007）。新增 Choice 追加到现有 L4 项目配置，不重写其他配置。目录和全部项目配置在同一事务内更新，失败整体回滚。

内置类别稳定别名不变。自定义类别使用名称与大类派生的稳定标识，实例 metadata 中保留 `{id,label,group}`，供校验、复制、导出和离线再导入使用。既有标注不回写、不迁移；新类别不会把原有家具自动改类。

## 恢复边界

旧镜像不认识自定义类别，因此使用新类别产生标注后，不能直接降级旧镜像继续标注。应优先修复当前版本，或使用支持自定义类别的后续镜像。不得用升级前数据库覆盖新增标注。

上一镜像归档在仓库外运行目录 `images/hanning-label-studio-1.23.2-chair-move-8ab0abec-linux-arm64.tar`。仅在确认尚未创建或使用自定义类别时，才可将 env 镜像切回上一版本并保留最新数据卷。本次不宣称已完成旧镜像读取新类别的兼容回滚。
