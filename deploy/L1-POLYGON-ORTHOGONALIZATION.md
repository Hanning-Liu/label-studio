# L1 Polygon 房间正交化

日期：2026-10-05。源码：`9d2ac5b12edd0286169b04d406b9469b408979a8`。

选中一个 L1 Polygon 房间后，右侧区域属性的类型选择下方显示“正交化（横平竖直）”。点击后按每条边更接近的水平／垂直方向对齐，并尽量减少顶点移动。原有凹形房间可保留凹角，连续共线顶点保持原数量与顺序。底部撤销／重做将本次调整作为一个操作处理；正交形状再次点击不产生修改。

方向判断采用原图像素比例，避免非正方形图片的百分比坐标导致方向判断错误。各水平边端点的 Y 坐标、垂直边端点的 X 坐标组成约束组，以组内均值求最小二乘位移。闭合边同样参与约束。顶点、区域 ID、类型、`from_name`、`to_name` 和已有元数据均保留，仅修改所选房间的坐标。

自交、重合顶点、越界、少于四个顶点、方向不明确的 45° 边，以及投影后边塌缩、反向或自交，均拒绝操作并保留原形状。只读、多选、绘制中、保存中和图片未加载时不可操作。操作不会联动移动其他房间、门或窗；正交化后仍由原有几何校验检查相邻区域衔接。
