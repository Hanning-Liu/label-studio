## 完成的修改

1. 前后端目录、项目模板和聚合校验支持 28 类。界面只允许代码与项目配置交集中的类别；旧项目未配置的新类别禁用并提供原因，没有可用类别时禁止绘制。不能将无法识别的类别悄悄改成 `other`。
2. 项目升级命令提供 dry-run、项目名称与配置 SHA-256 校验和事务更新。只插入缺少的 Choice，保留原 XML 的格式、属性、顺序和自定义布局；拒绝重复控件、冲突别名及不兼容 Choices；重复执行无修改。
3. “待绘制类别”只影响下一次绘制。“当前实例类别 → 应用类别”统一修改实例所有分块、配对类别和方向上下文，保留 ID、几何、父级、来源及方向证据；修改后待复核，同类别无操作。接入保存草稿、检查参考版本、修改、再保存及保存失败重试/窗口备份流程。
4. 家具填充独立于描边；普通/悬停/选中填充为 10%/12%/16%，屏幕边框为 1.5/2/3 px；预览 10% 与 2 px；Focus 4%，其他参考不填充。逻辑实例与原生活动分块分别拥有可见几何，避免重复填充；编辑装饰不接收鼠标事件。
5. 名称默认限定 Focus，同时保留选中及悬停名称；“全图名称”仅为显示状态。每实例一个 13 px 名称，重名时显示稳定 ID 后缀；屏幕坐标避让，必要时短引线，普通标签拥挤时隐藏。
6. 类别面板按可用宽度 4/2/1 列；主题高对比文字，选中勾选和加粗，键盘焦点轮廓与可聚焦类别说明。深色主题原生类别选择框也使用主题前景和背景。
7. 保留矩形工具点击启用及绘制完成回到 Move 的修复；复核成功后清除已完成的待复核提示。
