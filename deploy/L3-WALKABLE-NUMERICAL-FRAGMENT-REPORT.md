# L3 可通行区域浮点残片修复

日期：2026-10-06。功能提交：`7319e8315f5895d1c0e32b7ac3f87ef0a2283d08`。

## 原因与处理

任务 9 的 L3 草稿在 `Bedroom · Dressing/grooming` 中包含一个正常可通行区域，以及另一个几乎共线的三角形。后者的纵坐标为 `29.8` 和 `29.799999999999994`，原图高度只有约 `7.1e-14` 像素、面积约 `1.17e-12` 平方像素，是布尔差集在重合边界处产生的浮点残片。每个逻辑区域都会绘制文字，因而出现了截图中衣柜下角多余的“可通行”。

只对自动补余结果识别机器精度级别的共线残片：外环面积与周长、坐标量级对应的浮点误差界比较，不使用业务上的最小面积阈值。真实的小区域、狭窄通道及带孔区域继续保留，手工家具轮廓与父功能分区不改写。

重新生成时，即使几何等价判定认为原结果没有变化，也清理已保存的自动残片及其配对标签。父分区和家具未变时，保留真实可通行区域的原 ID 与坐标；若残片关联手工 Relations，仍阻断操作，要求人工处理关系。操作沿用草稿备份、参考版本检查、保存与撤销机制，不在页面载入时自动改写数据。
