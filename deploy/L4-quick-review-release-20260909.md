## 使用方法

1. 点击右侧组团标题，直接 Focus 并展开本组。点击实例名称选择和定位，复选框只表示该实例已被人工检查。
2. 勾选可复核实例，或点击“全选本组可复核项”，再点击“确认勾选的 N 个实例”。默认空选，不增加确认弹窗；整批校验通过后统一更新并保存。
3. 点击“开始复核”，再使用“确认并下一个”或 **Shift+Enter**。当前组团优先，保存成功后自动跨组；有效已复核项和需处理项不会被自动确认。
4. 右侧显示全任务、本组的已复核/待复核/需处理计数，按逻辑实例统计。默认筛选待复核，方向 `unknown` 可以复核。
5. 上方“已检查，确认复核”保留为只确认当前实例。输入框、下拉框、弹窗、绘制和保存期间不会响应连续复核快捷键。

操作区和列表各自滚动；右侧面板较矮时，可拉高 Regions 面板，或分别滚动查看按钮和实例。定位保留能完整容纳目标的当前视图，必要时平移或缩小，不自动放大。

保存失败时，本地修改保留，进度冻结并显示“本次 N 个确认尚未保存”。关闭应用可能出现的通用错误提示后，点击“仅重试保存”；它只保存已有修改，不重复确认。原操作为“确认并下一个”时，重试成功最多推进一次。参考或实例内容已变化则暂停连续复核。导出窗口备份仍然可用。

“全部已复核，待正式提交”不会执行 Submit。完整家具导出仍要求服务端来源记录；首次正式提交之前可以导出窗口原始结果备份。此规则来自现有导出逻辑。
