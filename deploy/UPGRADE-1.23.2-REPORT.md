## 数据、部署与安全

本地 QA 原有 2 项目、2 任务、1 标注、1 草稿，含 L3/L4 项目和参考同步绑定。
SQLite backup API 生成一致性快照；升级与回滚两次比较均通过完整性、外键和 83 张业务表指纹检查。
会话、迁移账本、SQLite 序列和 worker 心跳分别记录。没有忽略标注、草稿、来源或几何字段。

新镜像写入标注和草稿后，旧基线镜像直接使用同一个最新 QA 卷启动，读取结果完全一致，
回滚前后业务表无变化。未用旧数据库覆盖新标注。重启和再次升级后的回读也通过。
app、worker、网关均健康；验收后已停止 QA 容器并保留数据卷、镜像和日志。

隔离 Compose 使用独立数据卷、只读媒体副本和内部网络；固定上游网关只发布 `127.0.0.1:18085`。
`LABEL_STUDIO_HOST=http://localhost:18085`；浏览器应使用该地址。
本地存储配置 `USE_NGINX_FOR_UPLOADS=false`，由 Django 鉴权并透过 nginx 保留响应头。
HTML/SVG/XML 实测 HTTP 200 且带 `Content-Security-Policy: sandbox`；
SSRF 与本地 ML 防护均开启，密钥文件权限为 0600。云存储 X-Accel 路径仅有自动化测试，未实连验证。

   保留项目名、卷、端口和网络；输入及输出均保存在仓库外。
